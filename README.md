# PTIT-TRR1

## About this repository

This repository contains programming exercises (`.cpp` files) completed as coursework assignments from **Google Classroom**, as part of a course at PTIT (Posts and Telecommunications Institute of Technology).

The files are organized by homework/lab session, following the naming convention used in class (e.g., `hw10-1.cpp`, `hw11-2.cpp`, `b9tr44.cpp`).

## Purpose

- These exercises were written to fulfill course requirements and practice programming concepts taught in class.
- The code here reflects individual coursework, not a production project or open-source library.
- This repository is shared publicly for personal backup, portfolio, and reference purposes.

## Disclaimer

- These solutions may not represent the most optimal or idiomatic way to solve each problem — they were written as part of the learning process.
- Feel free to browse the code, but please note it was created for educational purposes tied to a specific course's assignments.
